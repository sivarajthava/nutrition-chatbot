# Hello Sivaraj Java Project

A simple Java application that prints "Hello Sivaraj!".

## Project Structure

```
.
├── src/
│   └── Main.java
├── .gitignore
└── README.md
```

## How to Compile and Run

### Direct execution (Java 11+):
```bash
java src/Main.java
```

### Or compile and run with class output directory:
```bash
javac -d bin src/Main.java
java -cp bin Main
```
